# IPL Performance Analytics (2008–2024)

**Technologies:** Python | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook

## Project Overview

Analysed **250,000+ IPL ball-by-ball records** from 2008–2024 to investigate batting, bowling, team performance and historical tournament trends.

Used Python for data cleaning, exploratory data analysis (EDA), statistical calculations and broadcast-style data visualisations.

## Dataset

Two datasets containing historical Indian Premier League data:

- `matches.csv` – Match results, teams, venues and toss decisions.
- `deliveries.zip` – Ball-by-ball records covering runs, wickets and individual player performances.

## Analysis Performed

- **Data Cleaning:** Standardised team names, handled missing values and validated historical records.
- **Batting Analysis:** Investigated leading run scorers and batting performance.
- **Bowling Analysis:** Examined bowling figures, wickets and bowling averages.
- **Team Performance:** Analysed win percentages, highest innings totals and team success.
- **Venue Analysis:** Explored historical performance across IPL grounds.
- **Data Visualisation:** Developed custom broadcast-style graphics using Matplotlib and Seaborn.

## Key Findings

- Sunrisers Hyderabad recorded 287/3 against Royal Challengers Bangalore in 2024, the highest innings total in the analysed dataset.
- Gujarat Titans achieved a 62.22% win percentage across 45 completed matches.
- Chennai Super Kings achieved a 58.23% win percentage across 237 completed matches.
- The analysis demonstrates differences in team consistency, scoring performance and historical results.
